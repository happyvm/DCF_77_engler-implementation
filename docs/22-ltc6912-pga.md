# Rev.0 LTC6912 programmable-gain stage

## Decision

Rev.0 keeps the historical LTC6912 family and freezes the `-1` gain law.

Preferred OPN:

```text
Analog Devices LTC6912IGN-1#PBF
16-pin narrow SSOP (GN)
industrial temperature grade
single 5 V operation
```

The LTC6912 family is currently listed by Analog Devices as `PRODUCTION`.

The `-1` option provides the following inverting gains:

```text
0, 1, 2, 5, 10, 20, 50, 100 V/V
```

The `-2` option stops at 64 V/V. Rev.0 deliberately keeps the `-1` option because the additional 100 V/V setting provides roughly 3.9 dB more available analog gain, which is useful with the compact integrated ferrite in weak-field environments.

The exact suffix used by Engeler remains historically unknown. Selecting `LTC6912IGN-1#PBF` is a rebuild choice.

## Why the GN-16 package

The GN package is preferred over the 12-pin DFN for Rev.0 because it is easier to inspect/rework and exposes the hardware `SHDN` pin.

The hardware shutdown function is not required for normal receive gain control, but keeping it available is useful for bring-up and power diagnostics.

Default hardware state:

```text
SHDN -> 100 kOhm pulldown to GND
```

Thus the PGA powers up enabled whenever `5V_AFE` is present.

An optional ECP5-controlled open-drain/transistor path may later force `SHDN` high, but the reference receive path must not depend on that feature.

## Supply and analog reference

Use:

```text
V+ = 5V_AFE
V- = GND
```

The LTC6912 generates an internal half-supply analog reference at `AGND`, nominally about 2.5 V.

For single-supply operation:

```text
AGND -> 1 uF || 100 nF to quiet ground
V+   -> 1 uF || 100 nF local bypass
```

The manufacturer specifies approximately 50 kOhm Thevenin source resistance at `AGND`; bypassing it is therefore important for noise and channel isolation.

Do not use the LTC6912 `AGND` pin as a general-purpose 2.5 V supply for the upstream circuitry.

## Fixed interface from LTC1562

The LTC1562 and LTC6912 each create their own mid-supply reference. Their DC offsets should not be multiplied by the high PGA gains.

Therefore the Rev.0 interface is explicitly AC-coupled:

```text
LTC1562 OUT
    |
    C_PGA = 1.0 uF
    |
    +------ 1 MOhm ------ LTC6912 AGND
    |
   INA
```

Reference capacitor specification:

```text
1.0 uF
>= 10 V rating
low-leakage MLCC or film
X7R acceptable because DC bias across this capacitor is small
```

At 77.5 kHz:

```text
|Xc| ~= 2.05 ohm
```

At the high-gain settings the LTC6912 nominal input impedance is about 1 kOhm, so this coupling reactance is negligible compared with the signal-path impedance. The resulting phase contribution at 77.5 kHz is far below one degree and does not act as a tuning element.

The 1 MOhm resistor defines the input bias when the PGA channel is in shutdown/open-input states and has negligible loading during normal gain settings.

## Gain table and serial codes

Each channel is programmed by one four-bit nibble. Channel B occupies the upper nibble; channel A occupies the lower nibble of the 8-bit SPI word.

For `LTC6912-1`:

| Nibble | Nominal gain | Gain dB |
|---|---:|---:|
| `0000` | 0 | shutdown/open input |
| `0001` | -1 | 0 dB |
| `0010` | -2 | 6 dB |
| `0011` | -5 | 14 dB |
| `0100` | -10 | 20 dB |
| `0101` | -20 | 26 dB |
| `0110` | -50 | 34 dB |
| `0111` | -100 | 40 dB |
| `10xx` | software shutdown | n/a |
| `11xx` | not used | n/a |

Do not intentionally use the `11xx` states. Manufacturer documentation warns that some unused states are not valid operating points.

## Channel assignment

Reference Rev.0:

```text
Channel A = main DCF77 receive path
Channel B = software shutdown by default
```

The second ADC channel remains available for diagnostics independently of the PGA. A useful default diagnostic path is the band-pass output before the PGA, routed through the second OPA2835 channel into LTC1407A CH1.

This avoids loading the LTC1562 output with two independently variable PGA input impedances.

A future board revision may use channel B for a second analog path, but the reference receiver does not depend on it.

## Why gain 100 is still acceptable at 77.5 kHz

The LTC6912-1 has an extended gain-bandwidth product at high gain. Manufacturer data gives a typical gain-bandwidth product around 33 MHz at gain 100, with a guaranteed minimum around 18 MHz over the specified grade.

Even the conservative ratio gives a closed-loop bandwidth far above 77.5 kHz:

```text
18 MHz / 100 ~= 180 kHz
33 MHz / 100 ~= 330 kHz typical
```

Therefore gain 100 remains usable at the DCF77 carrier frequency.

Any fixed phase shift of the PGA at 77.5 kHz is part of the deterministic analog path and can be included in the final PPS/phase calibration. The relevant requirement is stability and sufficient sideband bandwidth, not zero analog phase shift.

## Linear-range margin

For a single 5 V supply, the manufacturer specifies the approximate maximum linear input range at gain 100 as:

```text
~50 mVpp at the PGA input
```

which corresponds to roughly 5 Vpp at the PGA output.

Our downstream LTC1407A-1 path only uses a 2.5 V differential full span. Therefore the ADC should normally reach the AGC downshift threshold before the PGA itself reaches its absolute linear-range limit.

This is desirable: the digital AGC can detect loss of ADC headroom while the PGA still has analog margin.

## Gain-control philosophy

The gain loop must **not** track the DCF77 AM reduction.

The deliberate 100 ms / 200 ms carrier reduction is signal information. A fast AGC would partially erase that information and change the statistics seen by the detector.

Reference policy:

```text
AGC objective = ADC headroom / dynamic range
AGC objective != constant carrier amplitude
```

Once second timing is known, estimate carrier amplitude only from the stable carrier region:

```text
250 ms ... 950 ms after each second boundary
```

This excludes the AM reduction interval and avoids the final PM transition/tail region.

## Gain update timing

The recovered DCF77 PM sequence ends at approximately:

```text
992.774 ms
```

after the second boundary, leaving about 7.226 ms before the next second.

Therefore, after second synchronization, gain changes should occur only in the short tail around:

```text
~995 ms after the second boundary
```

This keeps gain-switch transients out of both the AM symbol interval and the 512-chip PM correlation window.

SPI activity should be deliberately slow and sparse:

```text
SPI clock target: ~100 kHz
8 clocks per update
update only when gain actually changes
```

At 100 kHz the transfer lasts only about 80 us, comfortably inside the available tail.

Blank/ignore a small sample interval around each gain update in diagnostic captures.

## Initial AGC thresholds

Reference starting policy:

```text
power-up gain = 100
```

For each second, using the 250...950 ms stable-carrier window, estimate a robust absolute ADC peak or high percentile.

Initial thresholds:

```text
ADC > 70% full scale
    -> reduce gain at the next safe tail

ADC < 12.5% full scale for 8 consecutive valid seconds
    -> increase gain one step at the next safe tail

otherwise
    -> hold gain
```

When reducing gain, the controller may skip multiple gain settings if the current peak predicts that a one-step change would still exceed roughly 50% full scale.

The exact software thresholds may be refined from captured data, but no resistor/capacitor or hardware gain setting is selected per board.

## Interaction with decoding

Every carrier/AM/PM metric must know which PGA gain produced it.

Preferred DSP boundary:

```text
raw ADC sample
    + current PGA gain code
        -> normalized detector sample / metric
```

For algorithms that compare amplitudes across gain changes, compensate by the known nominal PGA ratio rather than pretending the raw ADC scale is constant.

Do not change gain in the middle of a PM correlation sequence.

## SPI electrical interface to ECP5

The LTC6912 serial inputs are TTL/CMOS compatible, so 3.3 V ECP5 outputs can drive:

```text
CS/LD
DIN
CLK
```

Use small source-series resistors near the ECP5:

```text
~100 ohm starting value
```

because the bus is low-rate and does not need fast edges.

`DOUT` is not required for the receiver and should remain unconnected in Rev.0. This also avoids exposing a potentially 5 V logic-level output to a 3.3 V ECP5 input.

Route the three control traces away from the ferrite, OPA810 input and LTC1562 section nodes.

## Placement constraints

Treat LTC6912 as the last block of the 5 V AFE region.

Order:

```text
ferrite -> OPA810 -> LTC1562 -> LTC6912 | ADC island -> ECP5
```

Quilter rules:

- keep the PGA close to the LTC1562 output;
- place the 1 uF coupling capacitor and 1 MOhm bias resistor immediately at the PGA input;
- keep AGND bypass parts directly beside the IC;
- do not route PGA SPI underneath the ferrite or filter sections;
- keep the PGA output route short to the ADC coupling/OPA2835 island;
- no buck switch node or inductor in the PGA/filter region.

## Validation gates

The hardware values are fixed; validation confirms performance rather than selecting values.

Measure:

1. gain accuracy for all eight settings at 77.5 kHz;
2. phase at 77.5 kHz versus gain setting;
3. noise floor versus gain;
4. transition transient after a gain-code change;
5. ADC headroom and clipping threshold;
6. AM depth preservation with AGC enabled;
7. PM correlation amplitude before/after gain transitions;
8. self-interference generated by the sparse SPI update.

A failed validation should trigger an architectural correction, not per-unit calibration of passive values.

## Current reference chain

```text
TDK fixed tuned ferrite
  -> OPA810
  -> fixed LTC1562 77.5 kHz / 7.75 kHz BPF
  -> 1 uF AC coupling
  -> LTC6912IGN-1#PBF, channel A
  -> AC coupling / 1.25 V ADC rebias
  -> OPA2835
  -> LTC1407A-1 @ 930 kS/s
  -> ECP5
```
